# 🪟 Max Vidraçaria

Este é o site institucional da **Max Vidraçaria**, desenvolvido para apresentar os serviços de vidraçaria com um design moderno, responsivo e funcional. O objetivo principal é facilitar o contato do cliente e exibir o catálogo de soluções oferecidas.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as tecnologias fundamentais da web para garantir performance e leveza:

*   **HTML5**: Estruturação semântica do conteúdo.
*   **CSS3**: Estilização personalizada, Layout Responsivo (Media Queries) e Flexbox/Grid.
*   **JavaScript**: Manipulação do DOM para interatividade (como menu mobile, animações de scroll e validação de formulários).

## 🛠️ Funcionalidades

- [x] **Design Responsivo**: Adaptado para visualização em desktops, tablets e smartphones.
- [x] **Menu Mobile**: Navegação otimizada para dispositivos móveis.
- [x] **Galeria de Serviços**: Exibição clara de produtos como box para banheiro, espelhos, guarda-corpos e janelas.
- [x] **Formulário de Contato**: Integrado para facilitar orçamentos.
- [x] **Botão Flutuante do WhatsApp**: Acesso rápido para atendimento direto.
